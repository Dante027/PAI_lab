# PAI labs

Repozytorium zawiera trzy laboratoria z PAI.

## Lab1_PAI / HomePantry
Projekt .NET MAUI.

Uruchomienie standardowe:

```bash
dotnet restore
dotnet build
```

Najwygodniej otworzyć `HomePantry.csproj` w Visual Studio 2022 z zainstalowanym workloadem .NET MAUI.

## Lab2_PAI / home-pantry
Projekt React + Vite.

```bash
cd Lab2_PAI/home-pantry
npm install
npm run dev
```

## Lab3_PAI / spizarnia
Projekt Angular.

```bash
cd Lab3_PAI/spizarnia
npm install
npm start
```
